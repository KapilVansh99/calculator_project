# Simple Calculator Using HTML, CSS and JavaScript

## Overview

This is a simple web-based calculator developed using HTML, CSS, and JavaScript. The calculator performs basic arithmetic operations such as addition, subtraction, multiplication, and division through an interactive user interface.

## Features

* Addition, subtraction, multiplication, and division operations
* User-friendly interface
* Clear (C) button to reset the display
* Delete (⌫) button to remove the last entered character
* Responsive design for different screen sizes
* Error handling for invalid expressions

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)

## Project Structure

* `index.html` – Defines the structure of the calculator.
* `style.css` – Provides styling and layout.
* `script.js` – Implements calculator functionality and logic.

## How to Run

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server or any web browser.
4. Start performing calculations.
